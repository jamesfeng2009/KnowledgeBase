# 变更日志 CHANGELOG

> 本文档记录 EnterpriseKB 各版本的功能变更、Bug 修复与破坏性变更。
> 遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/) 规范。

## [2.3.0] - 2026-07-15

### 新增
- 引入 LangGraph 编排，支持多步推理与工具调用
- 新增 GraphRAG 实体抽取实验性模块
- 检索接口支持 RRF 融合算法可配置
- 管理后台新增检索效果评测看板

### 变更
- 重排序模型默认升级为 bge-reranker-v2
- 向量召回 top_k 上限从 20 提升至 50
- 日志默认格式改为 JSON

### 修复
- 修复并发上传同名文档导致分块错乱的问题
- 修复长文档分块时跨页标题丢失的问题
- 修复 SSE 流式响应偶发截断的 Bug

### 破坏性变更
- `POST /retrieve` 响应字段 `results` 重命名为 `items`，旧客户端需适配

## [2.2.0] - 2026-05-20

### 新增
- 支持多模态文档（图片 OCR 与表格识别）
- 新增插件市场与 `.ekp` 包格式
- 增加审计日志全量记录与导出

### 变更
- 数据库连接池默认值从 5 调整为 10
- 文档分块默认 overlap 从 50 调整为 64

### 修复
- 修复租户切换后缓存未隔离的问题
- 修复时区显示不一致（统一存储 UTC）

### 破坏性变更
- 废弃 `v1` 接口，全面切换至 `/api/v2`

## [2.1.0] - 2026-03-10

### 新增
- 新增行级安全（RLS）多租户隔离
- 支持文档版本管理与差异对比
- 新增 Prometheus 指标暴露端点 `/metrics`

### 变更
- Embedding 支持批量请求，吞吐提升 3 倍
- 前端迁移至 Astro Islands 架构

### 修复
- 修复高并发下 Redis 连接泄漏
- 修复 PDF 表格解析乱码

## [2.0.0] - 2026-01-05

### 新增
- 全新重构版本，前后端分离架构
- 引入 pgvector 替代独立向量数据库
- 支持 Docker Compose 一键部署

### 破坏性变更
- 整体重构，与 1.x 不兼容，需执行数据迁移脚本
- 配置文件格式从 `.env` 迁移至 `yaml`
- 数据库表结构重构，需重建索引

## [1.5.2] - 2025-11-18

### 修复
- 紧急修复鉴权绕过漏洞 CVE-2025-xxxx（建议立即升级）
- 修复文档删除后向量残留问题

## [1.5.0] - 2025-09-30

### 新增
- 支持混合检索（向量 + BM25）
- 新增重排序模块

### 变更
- 优化大文档解析内存占用

## 升级指引

| 当前版本 | 目标版本 | 注意事项 |
| --- | --- | --- |
| 1.x | 2.0 | 必须执行 `ekb migrate-from-v1` |
| 2.0-2.1 | 2.2 | v1 接口下线，检查第三方调用 |
| 2.2 | 2.3 | 响应字段 `results`→`items` |

## 版本号规则

采用 `主版本.次版本.修订号`：

- **主版本**：含破坏性变更，需人工迁移
- **次版本**：向后兼容的新功能
- **修订号**：向后兼容的 Bug 修复

> 详细的提交记录请查看 Git 历史，每个版本均有对应的 Git Tag。
