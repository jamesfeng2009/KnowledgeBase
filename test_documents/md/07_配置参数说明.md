# 配置参数说明

> 本文档汇总 EnterpriseKB 全部可配置参数，含环境变量、配置文件项、默认值与推荐配置。

## 1. 配置加载顺序

配置按以下优先级从高到低覆盖：

1. 命令行参数（`--option value`）
2. 环境变量（`EKB_` 前缀，下划线分隔）
3. 配置文件（`config/local.yaml`）
4. 内置默认值

## 2. 服务相关

| 参数 | 环境变量 | 默认值 | 说明 |
| --- | --- | --- | --- |
| server.host | EKB_SERVER_HOST | 0.0.0.0 | 监听地址 |
| server.port | EKB_SERVER_PORT | 8000 | 监听端口 |
| server.workers | EKB_SERVER_WORKERS | 4 | gunicorn worker 数 |
| server.timeout | EKB_SERVER_TIMEOUT | 60 | 请求超时(秒) |
| server.cors_origins | EKB_CORS_ORIGINS | * | 允许的跨域来源 |

## 3. 数据库相关

| 参数 | 默认值 | 推荐值 | 说明 |
| --- | --- | --- | --- |
| database.host | 127.0.0.1 | 内网地址 | 主机 |
| database.port | 5432 | 5432 | 端口 |
| database.name | enterprise_kb | - | 库名 |
| database.pool_size | 10 | 20 | 连接池大小 |
| database.max_overflow | 20 | 40 | 溢出连接 |
| database.statement_timeout | 30000 | 10000 | 语句超时(ms) |

## 4. Redis 相关

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| redis.url | redis://localhost:6379/0 | 连接地址 |
| redis.max_connections | 50 | 最大连接 |
| redis.task_queue | ekb_tasks | 任务队列名 |

## 5. Embedding 配置

```yaml
embedding:
  provider: openai          # openai / local / azure
  model: text-embedding-3-small
  api_key: ${EMBEDDING_API_KEY}
  base_url:                 # 自定义端点
  dim: 1536
  batch_size: 64            # 单次请求批大小
  max_concurrency: 4        # 并发数
  cache_enabled: true       # 启用向量缓存
```

## 6. LLM 配置

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| llm.provider | openai | 模型供应商 |
| llm.model | gpt-4o-mini | 模型名 |
| llm.temperature | 0.2 | 采样温度 |
| llm.max_tokens | 1024 | 最大生成 token |
| llm.timeout | 60 | 超时(秒) |
| llm.retry | 3 | 重试次数 |
| llm.fallback_model | gpt-3.5-turbo | 降级模型 |

## 7. 检索配置

```yaml
retrieval:
  top_k: 5                  # 召回数量
  rerank: true              # 启用重排序
  rerank_model: bge-reranker-v2
  score_threshold: 0.35     # 最低相似度
  hybrid:
    vector_weight: 0.7
    keyword_weight: 0.3
    fusion: rrf             # rrf / weighted
```

## 8. 文档解析配置

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| parser.chunk_size | 512 | 分块字符数 |
| parser.chunk_overlap | 64 | 重叠字符 |
| parser.max_file_size | 52428800 | 单文件上限(字节) |
| parser.ocr_enabled | false | 启用 OCR |
| parser.supported_types | [pdf,docx,md,txt] | 支持类型 |

## 9. 安全配置

```yaml
security:
  jwt_secret: ${EKB_JWT_SECRET}
  jwt_expire_minutes: 120
  refresh_expire_days: 7
  password_min_length: 10
  rate_limit:
    enabled: true
    per_minute: 60
  encryption:
    algorithm: AES-256-GCM
    key: ${EKB_ENC_KEY}
```

## 10. 日志与可观测性

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| log.level | INFO | 日志级别 |
| log.format | json | 输出格式 |
| log.path | /var/log/ekb | 日志目录 |
| metrics.enabled | true | 暴露 Prometheus 指标 |
| tracing.enabled | false | OpenTelemetry 链路追踪 |
| tracing.endpoint | http://otel:4317 | OTLP 接收端 |

## 11. 多租户配置

```yaml
tenant:
  isolation: rls            # rls / schema / database
  default_quota:
    documents: 10000
    storage_gb: 50
    queries_per_day: 5000
```

## 12. 环境变量清单

```dotenv
# 必填
EKB_JWT_SECRET=
EKB_ENC_KEY=
EMBEDDING_API_KEY=
LLM_API_KEY=
POSTGRES_PASSWORD=

# 可选
EKB_SERVER_PORT=8000
EKB_LOG_LEVEL=INFO
EKB_TENANT_ISOLATION=rls
```

## 13. 推荐生产配置

- `server.workers` 设为 CPU 核数的 2 倍
- `database.pool_size` 按 `(workers * 2) + 冗余` 估算
- `embedding.max_concurrency` 不超过供应商限流阈值
- `log.level` 生产环境设为 `WARNING`，仅错误时排查再调细

> 所有密钥类参数必须通过环境变量或 Vault 注入，禁止写入配置文件仓库。
