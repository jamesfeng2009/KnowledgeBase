课程规划调整版

AI Agent 全栈教程 — 课程完整规划（项目调整版）

规划日期：2026 年 7 月 总周期：40 周（4 个 Phase） 课程模块：12 个核心模块 / 82 节课程 差异化亮点：全栈产品闭环 + 企业级工程化 + 商业化落地 技术栈：Python FastAPI + Go APISIX + Astro + LangChain/LangGraph

一、本次调整说明

调整背景：原课程规划（2026年6月版）以竞品分析为基础，设计了12个核心模块的AI Agent全栈教程，差异化亮点为"可靠性工程 + Rust 基础设施"。现基于实际项目执行需求，将课程规划与4阶段40周执行计划深度对齐，实现"课程录制 + 产品开发 + 内容输出"三位一体的闭环模式。

核心调整点：

  • 时间维度调整：从无明确时间线的模块列表，调整为4个Phase × 10周 = 40周的精确执行计划，每周周一至周六均有明确任务分解
  • 差异化调整：从"Rust 基础设施"调整为"全栈产品闭环"——学员不仅学课程，还跟着从0到1构建一个真实的企业级AI知识库产品（V1.0→V3.1），产品本身就是课程的最佳实战项目
  • 技术栈调整：从竞品的 Node.js/TypeScript + LangChain.js，调整为 Python FastAPI（AI后端）+ Go APISIX（API网关）+ Astro（前端），更贴近企业级生产环境
  • 教学模式调整：从纯课程录制，调整为"周一/三/五课程录制 + 周二/四产品开发 + 周六内容输出"的混合模式，学员可以同时学习课程和参与产品构建
  • 商业化调整：新增Phase 3商业化模块（17节课程），覆盖SaaS定价、企业销售、开放API、插件系统、Marketplace、私有化部署、国际化等企业级话题
  • 课程总量调整：从原计划的约60节课程扩展为82节课程，新增多模态AI、Agent安全、知识图谱、工程化最佳实践等高级模块

调整原则：课程内容服务于产品构建，产品构建反哺课程内容——每一节课的技术点都在产品中有对应的实现，每一个产品功能都有对应的课程讲解，形成"学以致用、用以促学"的正向循环。

二、竞品分析摘要（调整版）

竞品概况：「前端转 AI Agent 全栈通关秘籍」（作者"神光"，品牌"神光的编程秘籍"），共28篇文章，配套GitHub代码仓库。技术栈为 Node.js / TypeScript + LangChain.js，使用通义千问 qwen-plus 作为大模型，覆盖从大模型原理到 Agent 全栈开发的完整链路。定位面向有前端/Node.js基础、想转AI Agent方向的开发者，偏应用层而非算法层。

竞品优势：(1) 内容口语化、入门友好；(2) 28篇文章覆盖面广；(3) 配套GitHub代码可运行；(4) 面向前端转AI的明确人群。

竞品不足：(1) 缺少生产级部署与运维内容；(2) 无安全防护与合规相关内容；(3) 无多模态AI内容；(4) 无知识图谱与高级RAG内容；(5) 无商业化与产品运营内容；(6) 缺少企业级架构设计（多租户/SSO/API网关/插件系统）；(7) 技术栈单一（仅Node.js），缺少多语言架构视角；(8) 无真实产品作为实战项目。

五、差异化策略（调整版）

原差异化亮点：可靠性工程 + Rust 基础设施

调整后差异化亮点：全栈产品闭环 + 企业级工程化 + 商业化落地

差异化亮点 1：全栈产品闭环（核心壁垒）

竞品只有课程和示例代码，本课程同时构建一个真实的企业级AI知识库产品（从V1.0到V3.1，100+功能，真实上线运营）。学员不仅学课程，还跟着从0到1构建产品，每个技术点都有对应的product实现。课程即产品，产品即课程——这是竞品无法复制的核心壁垒。

  • Phase 0：产品V1.0本地版（基础对话 + RAG知识库）
  • Phase 1：产品V1.0线上版（K8s部署 + 监控 + 正式上线）
  • Phase 2：产品V2.0进阶版（多模态 + 安全 + 知识图谱）
  • Phase 3：产品V3.1企业版（多租户 + SSO + 插件 + Marketplace + 国际化）

差异化亮点 2：企业级工程化（深度壁垒）

竞品偏应用层入门，本课程深入企业级工程化：多语言架构（Python + Go + TypeScript）、微服务架构（API网关 + 多服务）、K8s生产部署、全链路监控（Prometheus + Grafana + ELK）、安全防护（Prompt注入 + PII + 红队测试）、FinOps成本工程。学员学完不仅会写AI应用，还能构建企业级生产系统。

  • 多语言架构：Python FastAPI（AI后端）+ Go APISIX（API网关）+ Astro（前端）
  • 生产部署：Docker → K8s → CI/CD → 监控告警 → SRE全链路
  • 安全防护：LlamaGuard + Presidio + WAF + 红队测试 + 合规审计
  • 可观测性：日志 + 指标 + 链路追踪 + 告警 + Dashboard

差异化亮点 3：商业化落地（商业壁垒）

竞品无商业化内容，本课程新增Phase 3（20节课程）专门讲商业化：SaaS定价策略、企业销售流程、POC转化、开放API与SDK、插件系统与生态、Agent模板Marketplace、私有化部署、国际化与海外推广。学员学完不仅会技术，还懂如何将AI产品商业化变现。

  • SaaS商业化：分层定价（免费/Pro/Pro+/企业版）+ 计费系统 + 订阅管理
  • 企业级功能：多租户 + SSO（SAML/OAuth/OIDC）+ RBAC权限
  • 开放生态：开放API + 多语言SDK + 插件系统 + Marketplace
  • 私有化部署：一键安装 + 离线部署 + 升级回滚
  • 国际化：多语言 + 多Region + GDPR合规 + 海外推广

差异化亮点 4：可靠性工程（保留原亮点）

保留原规划的可靠性工程亮点，但实现方式从Rust调整为Python + Go多语言架构。包括：降级策略（多模型fallback/本地模型备用）、熔断与限流（API网关层熔断/令牌桶限流）、故障自愈（健康检查/自动重启/自动扩缩容）、SLO保障（P99延迟<3s/可用性>99.9%/错误率<0.1%）、全链路可观测（日志/指标/追踪/告警）。

十二、总结

本次课程规划调整的核心思路是"课程+产品双线并行、4阶段40周精确执行"。相比原规划，调整后的方案具有以下优势：

  1. 可执行性更强：每周周一至周六都有明确任务分解，不再是模糊的模块列表，而是精确到每天做什么、完成标准是什么、交付物是什么
  2. 差异化更明显：从"Rust基础设施"调整为"全栈产品闭环"，学员跟着40周计划构建一个真实的企业级产品，这是竞品无法复制的核心壁垒
  3. 商业化更完整：新增Phase 3（20节课程）覆盖商业化全链路，学员不仅学技术，还学如何将AI产品变现
  4. 课程更系统：从28篇扩展为82节系统化课程，覆盖从大模型基础到企业级商业化的完整链路
  5. 技术更前沿：新增多模态AI、Agent安全、知识图谱、GraphRAG等前沿技术模块
  6. 工程更深入：从应用层入门深入到企业级工程化（K8s/监控/安全/FinOps），学员能构建生产级系统

最终目标：40周完成82节系统化课程 + 企业级AI知识库产品V3.1（100+功能/多语言/多Region/插件生态/Marketplace/私有化部署），实现课程教学与产品商业化的双赢。
